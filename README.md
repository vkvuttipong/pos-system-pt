# 🛍️ ระบบ POS - จัดการร้านค้า

ระบบจัดการจุดขายแบบเว็บ (Point of Sale System) ที่พัฒนาด้วย Node.js และ Express.js

## ✨ ฟีเจอร์หลัก

- ✅ **ขายสินค้า** - เพิ่ม/ลดรายการสินค้าและจำนวนได้อย่างชาญฉลาด
- 💰 **รองรับหลายวิธีชำระเงิน** - เงินสด หรือ โอนธนาคาร
- 🔄 **คืนสินค้า** - ระบบจัดการการคืนสินค้าขายคืน
- 📦 **จัดการคลัง** - เพิ่ม/ลบ/แก้ไขข้อมูลสินค้าได้ง่าย
- 📊 **รายงานยอดขาย** - ดูรายงานรายวันพร้อมสรุปยอดขาย
- 📁 **บันทึกข้อมูลใน Excel** - ข้อมูลสินค้าและรายการขาย เก็บเป็นไฟล์ Excel
  - `data/inventory.xlsx` - ข้อมูลสินค้าทั้งหมด
  - `data/YYYYMMDD.xlsx` - รายการขายแต่ละวัน (เช่น `20260329.xlsx`)

## 🚀 การติดตั้งและรัน

### ข้อกำหนดเบื้องต้น
- Node.js v14 ขึ้นไป
- npm

### ขั้นตอนการติดตั้ง

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. รันเซิร์ฟเวอร์
npm start

# 3. เปิดในเบราว์เซอร์
# http://localhost:3000
```

## 📖 การใช้งาน

### 🛒 แท็บขายสินค้า
1. **ค้นหาสินค้า** - พิมพ์ชื่อหรือรหัสสินค้าในกล่องค้นหา
2. **เลือกสินค้า** - คลิกสินค้าที่ต้องการ ป้อนจำนวน แล้วเพิ่มเข้าตะกร้า
3. **เลือกวิธีชำระเงิน** - เลือก "เงินสด" หรือ "โอนธนาคาร"
4. **ชำระเงิน** - คลิก "✅ ชำระเงิน" เพื่อสรุปการขาย
5. **คืนสินค้า** - คลิก "🔄 คืน" บนรายการสินค้าในตะกร้าเพื่อทำการคืน

### 📦 แท็บคลัง
1. **เพิ่มสินค้า** - กรอก รหัส ชื่อ ราคา จำนวน แล้วคลิก "เพิ่มสินค้า"
2. **ดูรายการสินค้า** - แสดงรายการสินค้าทั้งหมดพร้อมจำนวนคงเหลือ
3. **แก้ไขสินค้า** - คลิก "แก้ไข" ในตารางแล้วอัปเดตข้อมูล
4. **ลบสินค้า** - คลิก "ลบ" เพื่อลบรายการสินค้า

### 📊 แท็บรายงาน
1. **เลือกวันที่** - เลือกวันที่จากรายการแบบเลื่อน (หรือเว้นว่างเพื่อดูวันนี้)
2. **ดูรายงาน** - คลิก "📊 ดูรายงาน" เพื่อดูสรุปยอดขาย
3. **ข้อมูลรายงาน**:
   - ยอดขายรวม
   - ยอดคืนรวม (แสดงเป็นลบ)
   - ยอดเงินสด
   - ยอดโอนธนาคาร
   - ยอดสุทธิ
   - รายละเอียดทุกรายการ

## 🔌 API Endpoints

### GET /api/inventory
ดึงรายการสินค้าทั้งหมด

```bash
curl http://localhost:3000/api/inventory
```

### POST /api/product
เพิ่มหรืออัปเดตสินค้า

```bash
curl -X POST http://localhost:3000/api/product \
  -H "Content-Type: application/json" \
  -d '{"code":"P001","name":"สินค้า","price":100,"quantity":10}'
```

### POST /api/sell
บันทึกการขาย

```bash
curl -X POST http://localhost:3000/api/sell \
  -H "Content-Type: application/json" \
  -d '{"code":"P001","quantity":2,"payment":"cash"}'
```

### POST /api/refund
บันทึกการคืนสินค้า

```bash
curl -X POST http://localhost:3000/api/refund \
  -H "Content-Type: application/json" \
  -d '{"code":"P001","quantity":1}'
```

### GET /api/report
ดึงรายงานยอดขาย

```bash
# วันนี้
curl http://localhost:3000/api/report

# วันที่ระบุ
curl http://localhost:3000/api/report?date=20260329
```

### GET /api/available-dates
ดึงรายชื่อวันที่มีข้อมูล

```bash
curl http://localhost:3000/api/available-dates
```

### DELETE /api/product/:code
ลบสินค้า

```bash
curl -X DELETE http://localhost:3000/api/product/P001
```

## 🎨 แนวคิดการออกแบบ

- **Responsive Design** - ใช้งานได้บนเดสก์ท็อป แท็บเล็ต และมือถือ
- **Modern UI** - ใช้ Gradient สีสัวยงา ปุ่มสวย และ Animations
- **Thai Language** - อินเทอร์เฟซเป็นภาษาไทยทั้งหมด
- **Real-time Updates** - ข้อมูลอัปเดตทันทีหลังการกระทำ

## 🛠️ Dependencies

- **express** - เว็บเฟรมเวิร์ก
- **body-parser** - ประมวลผล JSON requests
- **xlsx** - จัดการไฟล์ Excel
- **moment** - จัดการวันที่และเวลา

## 📝 หมายเหตุ

- ข้อมูลสินค้าต้องมี `code`, `name`, `price`, `quantity`
- วันที่ในไฟล์ถูกบันทึกเป็นรูปแบบ `YYYYMMDD` (เช่น `20260329`)
- ระบบรองรับ 2 วิธีชำระเงิน: `cash` (เงินสด) และ `transfer` (โอนธนาคาร)
- ยอดคืนสินค้าถูกบันทึกเป็นค่าลบในไฟล์ Excel
